# Pad Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a **Pad Kit** machine: a sample drum machine with 16 pads.
Each pad holds up to 4 velocity layers and has its own tone and envelope
knobs, a play mode and a mute group. It has its own 16-row pad lane in
the dock, and whole kits save and load as `.padkit` files.

**Architecture:**
- A new engine module, `acid-engine/src/padkit/`, reuses the Sampler's
  voice (`sampler::voice::Voice`), audio (`SampleData`) and PCM storage.
- Each pad's knobs are turned into the Sampler's `SlotSettings`, so tune,
  filter, envelope, pan, reverse and declick all come from code that is
  already tested.
- Pad Kit patterns are note patterns: a note's pitch 0–15 is the pad.
  They play through the sequencer's note path, which carries velocity,
  length and note-offs. `SeqEvent::PolyOn` gains an `accent` flag.
- In the app:
  - a new panel (`padkit_panel.rs`);
  - load and undo plumbing (`padkit_load.rs`, `document.rs`);
  - a new `LaneKind::Pads` in the dock;
  - kit files (`padkit_file.rs`).

**Tech Stack:** Rust 2024 workspace (`acid-engine`, `app`), egui/eframe
0.31, `rtrb`, `ron`/`serde`, `rfd`.

**Spec:** `docs/superpowers/specs/2026-10-17-pad-kit-design.md`. It
includes the 2026-10-17 dock decision (the pad lane).

## Global Constraints

- **Real-time safety.** The audio thread must not allocate or free:
  `Engine::process`, `EngineHost::process`, and every `Command` the host
  applies.
  - Every new audio-side path gets a `count_allocs` case in
    `crates/acid-engine/tests/no_alloc.rs`.
  - New audio reaches the engine as `Arc<SampleData>` built on the UI
    thread.
  - What leaves the engine goes back through a `Dispose*` event.
- **Naming.** User-facing text never names a hardware product or
  manufacturer.
  - Menu label: **"Pad Kit"**. Name stem: **"Pads"**.
  - File extension: **`padkit`**.
- **Fixed values:**
  - `PADS = 16` and `MAX_LAYERS = 4`.
  - Fades: mute-group choke, self-retrigger and Gate release all use
    **5 ms**.
  - Accent raises velocity by `Accent × 127`, clamped to 127, **before**
    the layer is chosen.
  - Even layer split: 1 layer → 1–127; 2 → 1–63, 64–127;
    3 → 1–42, 43–85, 86–127; 4 → 1–31, 32–63, 64–95, 96–127.
  - Velocity scales level linearly (`vel / 127`), as the Sampler does.
- **Per-pad knobs** (all automatable):

  | Knob | Range | Default |
  |---|---|---|
  | Tune | −24…+24 semitones, continuous | 0 |
  | Decay | 0–100 %; 100 % = open to the sample's end | 100 % |
  | Level | 0–100 %, kit level curve | 80 % |
  | Pan | L–R | centre |
  | Cutoff | 20 Hz…20 kHz, exponential | open |
  | Resonance | 0–100 % | 0 |
  | Start | 0–100 % of the sample | 0 |
  | End | 0–100 % of the sample | 100 % |
  | Reverse | off / on | off |
  | Mode | One-shot / Gate | One-shot |
  | Mute group | Off, 1–4 | Off |

  Kit knobs: Volume (70 %) and Accent (50 %).

  ```rust
  // padkit/mod.rs
  pub const PADS: usize = 16;
  pub const MAX_LAYERS: usize = 4;
  // padkit/pad.rs
  #[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
  pub struct Layer {
      pub vel_lo: u8, pub vel_hi: u8,          // inclusive, 1..=127
      pub name: String,                        // file stem, ≤ 24 chars
      pub sample_rate: u32, pub channels: u8,  // 1 or 2
      #[serde(with = "crate::sampler::slot::pcm_codec")]
      pub pcm: Vec<i16>,                       // interleaved
  }
  impl Layer {
      pub fn new(name: &str, sample_rate: u32, channels: u8, samples: &[f32]) -> Layer; // range 1..=127
      pub fn frames(&self) -> u32;
      pub fn memory_bytes(&self) -> usize;     // pcm.len() * 4, as SlotData
      pub fn to_sample(&self) -> SampleData;   // SampleData::from_pcm
      /// Why this layer could not play, if it couldn't (no audio, bad channels/rate, too long).
      pub fn problem(&self) -> Option<&'static str>;
  }
  #[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize)]
  pub struct Pad {
      #[serde(default)] pub name: String,      // "" = shown as the first layer's name, or "P<n>"
      #[serde(default)] pub layers: Vec<Layer>,
  }
  impl Pad {
      /// Sets every layer's range to the even split for the layer count.
      pub fn split_evenly(&mut self);
      /// Index of the layer `vel` plays (first match), if any.
      pub fn layer_for(&self, vel: u8) -> Option<usize>;
      pub fn is_well_formed(&self) -> bool;    // ≤ MAX_LAYERS, ranges 1..=127 with lo ≤ hi, layers valid
      pub fn memory_bytes(&self) -> usize;
      /// What the pad lane and the pad grid show.
      pub fn label(&self, pad: usize) -> String;
  }
  #[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
  pub struct PadKitMachine {
      pub patterns: Vec<NotePattern>,          // PATTERNS of them; pitch < PADS
      #[serde(default = "empty_pads", deserialize_with = "exactly_pads")]
      pub pads: Vec<Pad>,                      // exactly PADS
  }
  impl PadKitMachine { pub fn memory_bytes(&self) -> usize; }
  // params.rs
  param_enum!(PadKitParam { Volume => "Volume", Accent => "Accent" });
  param_enum!(PadParam {
      Tune => "Tune", Decay => "Decay", Level => "Level", Pan => "Pan",
      Cutoff => "Cutoff", Resonance => "Resonance", Start => "Start", End => "End",
      Reverse => "Reverse", Mode => "Mode", Group => "Mute Group",
  });
  // MachineParam gains: PadKit(PadKitParam), Pad(u8, PadParam)
  pub mod pad_map {
      pub fn tune_semitones(v: f32) -> f32;   // (v - 0.5) * 48.0
      pub fn decay_seconds(v: f32) -> Option<f32>; // None at v ≥ 0.999 (open); else exp(v, 0.01, 4.0)
      pub fn cutoff_hz(v: f32) -> f32;         // exp(v, 20.0, 20_000.0)
      pub const GROUPS: usize = 5;             // Off, 1..=4
      pub fn group(v: f32) -> u8;              // step_index(v, 5): 0 = Off
      pub fn gate(v: f32) -> bool;             // Mode: on(v) = Gate
  }
  // MachineType::PadKit; label "Pad Kit"; stem "Pads"; transposes() false
  // MachineBody::PadKit(PadKitMachine); body_accessors!(padkit, padkit_mut, PadKit, PadKitMachine)
  // PROJECT_VERSION = 7
  ```

  re-deriving them. If they live inline, move the shared part into a

```rust
//! A pad's knobs in real units, as the Sampler voice takes them.

use crate::params::{MachineParam, PadParam, on, pad_map, sampler_map};
use crate::sampler::settings::SlotSettings;
use std::f32::consts::{FRAC_PI_2, SQRT_2};

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct PadSettings {
    pub voice: SlotSettings,
    pub start: f32,
    pub end: f32,
    pub gate: bool,
    pub group: u8,
}

impl PadSettings {
    pub fn set(&mut self, p: PadParam, v: f32) {
        let v = v.clamp(0.0, 1.0);
        let s = &mut self.voice;
        match p {
            PadParam::Tune => {
                let semis = pad_map::tune_semitones(v);
                s.tune = semis.trunc() as i32;
                s.fine_cents = semis.fract() * 100.0;
            }
            PadParam::Decay => match pad_map::decay_seconds(v) {
                // Open: the amp holds until the sample (or the gate) ends.
                None => s.sustain = 1.0,
                Some(secs) => {
                    s.sustain = 0.0;
                    s.decay_s = secs;
                }
            },
            PadParam::Level => s.level_gain = sampler_map::level_gain(v),
            PadParam::Pan => {
                let angle = v * FRAC_PI_2;
                s.pan_l = angle.cos() * SQRT_2;
                s.pan_r = angle.sin() * SQRT_2;
            }
            PadParam::Cutoff => {
                s.cutoff_knob = v;
                s.cutoff_hz = pad_map::cutoff_hz(v);
            }
            PadParam::Resonance => s.resonance = v,
            PadParam::Start => self.start = v,
            PadParam::End => self.end = v,
            PadParam::Reverse => s.reverse = on(v),
            PadParam::Mode => self.gate = pad_map::gate(v),
            PadParam::Group => self.group = pad_map::group(v),
        }
    }
}

impl Default for PadSettings {
    fn default() -> Self {
        let mut voice = SlotSettings::default();
        // A drum hit: instant attack, and the Gate release is the 5 ms fade.
        voice.attack_s = 0.0005;
        voice.release_s = 0.005;
        let mut s = PadSettings { voice, start: 0.0, end: 1.0, gate: false, group: 0 };
        for p in PadParam::ALL {
            s.set(p, MachineParam::Pad(0, p).info().default);
        }
        s
    }
}
```

- [ ] **Step 6: Implement `machine.rs`.** The parts:
  - **State:**
    - `samples: [[Option<Arc<SampleData>>; MAX_LAYERS]; PADS]`
    - `play: PadPlay`
    - `settings: [PadSettings; PADS]`
    - `voices: [Voice; VOICES]` with `const VOICES: usize = 16`
    - `clock: u32` (voice age)
    - `volume` and `accent` (0..=1)
    - chunk buffers, as in the Sampler
  - **`note_on(pad, vel, accent, live)`:**
    1. Return if `pad as usize >= PADS` or `vel == 0`.
    2. `let vel = if accent { (vel as f32 + self.accent * 127.0).round().min(127.0) as u8 } else { vel };`
    3. `let Some(layer) = self.play.layer_for(pad, vel) else { return };`
    4. Take that layer's sample: `let Some(sample) = &self.samples[pad][layer] else { return };`
    5. Build the segment:
       ```rust
       let frames = sample.frames() as f64;
       let st = &self.settings[pad];
       let (a, b) = ((st.start.min(st.end) as f64 * frames).floor(), (st.end.max(st.start) as f64 * frames).ceil());
       if b - a < 1.0 { return; }
       let semis = (st.voice.tune as f64 + st.voice.fine_cents as f64 / 100.0) / 12.0;
       let rate = (sample.sample_rate as f64 / self.sample_rate as f64 * 2f64.powf(semis)).max(1e-6);
       let seg = Segment { start: a, end: b, reverse: st.voice.reverse, looping: None, rate };
       ```
    6. Choke, 5 ms (`Voice::choke`): every active, not-already-releasing
       voice of this pad, and of every other pad whose `group` equals this
       pad's non-zero group.
    7. Pick a voice: the first inactive one, else the first `tail_only()`
       one, else the oldest (smallest `age`).
    8. Start it with `v.start(&seg, pad, layer as u8, vel, live, self.clock)`.
       The Voice's `slot` holds the pad and its `key` holds the layer.
    9. `self.clock = self.clock.wrapping_add(1)`.
  - **`note_off(pad, live)`:** for Gate pads only, release
    (`v.release(self.settings[pad].voice.release_s)`) every held voice of
    that pad with matching `live`. One-shot pads ignore it.
  - **`pattern_off`:** as `note_off`, for every non-live voice of a Gate
    pad.
  - **`all_off` / `reset`:** kill every voice.
  - **`render`:** zero the chunk buffers. For each active voice, render
    `samples[v.slot][v.key as usize]` with `settings[v.slot].voice` into
    them. A voice whose sample is now `None` is killed. Then add the
    buffers × `volume` into the outputs. Chunk exactly as
    `Sampler::render` does.
  - **`swap_sample`:** kill the pad's voices, swap. **`swap_play`:** swap.
    Voices keep their started segment.
  - **`set_param`:**
    - `Volume` → `v.powi(2)`, as the Sampler's Volume;
    - `Accent` → `v`.
  - The Sampler's `Voice` fields `slot` and `key` are public. If
    `Voice::start` takes `key: u8`, the layer fits. If anything here
    needs a change to `Voice`, keep the Sampler's behaviour identical and
    say so in the report.

  ```rust
      /// A malformed pad refuses the whole file: "pad 3: layer 2 has no audio".
  ```

- Semantics, from the spec:
  - **Save** writes every pad's layers and the kit's and pads' param
    values. Channel params are not part of a kit.
  - **Load** replaces every pad and those param values in one
    `Edit::PadKitKit`, so one undo step. Patterns are untouched.
  - The parse uses the same budget the project-open path uses:
    `with_budget` via `pcm_codec`, half of free memory.
  - The memory warning uses the kit's `memory_bytes() * 2` minus the
    current pads' `memory_bytes()`, saturating.
  - A file that fails to parse, has the wrong `version`, has a pad count
    other than 16, or has a malformed pad is refused whole. The message
    reads `Could not load the kit: {reason}.` The reason names the pad
    1-based, e.g. `pad 3: layer 2 has no audio`.
  - Param entries that are not `PadKit`/`Pad` params, or are out of
    range, are refused.
