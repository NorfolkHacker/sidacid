# Phase 2: Bottom Editor Dock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every machine's pattern editor moves into one resizable dock at the bottom of the window, as stacked piano-roll lanes that share one time axis, with keyboard note entry; the rack above keeps only knobs, pads and pattern controls.

**Architecture:** A new `ui/dock.rs` draws an `egui::TopBottomPanel::bottom` with a header (snap, zoom, follow), a shared time ruler and a vertically scrolling stack of lanes. Each lane (`ui/lane.rs`, grown out of today's `polyroll.rs`) paints its machine's selected pattern with a shared horizontal scroll offset and its own pitch scroll, using a pure geometry type (`ui/lane_geom.rs`) that maps ticks and rows to pixels for melodic lanes (128 pitches) and drum lanes (8 instruments). Keyboard entry is a pure state machine (`ui/key_entry.rs`) fed by the dock when it has keyboard focus. Dock size goes in the app settings; each machine's lane height, collapse state and strip toggle go in the project (serde-defaulted, no version bump, no undo).

**Tech Stack:** Rust 2024, egui/eframe, serde + RON.

**Spec:** `docs/superpowers/specs/2026-10-16-dock-song-lanes-design.md` (section 2). Phase 1 is merged: every machine's pattern is a `NotePattern` reachable through `Project::roll(uid, slot)` / `roll_mut`.

## Decisions taken in this plan

| Question | Decision |
|---|---|
| Where lane height/collapse/strip live | `MachineEntry.lane: LaneView` in the project, `#[serde(default)]`, skipped when default; edited directly (no `Edit`, no dirty flag) — saved the next time the project is saved |

pub enum Snap {
    Quarter,
    Eighth,
    #[default]
    Step,
    Half,
    Tick,
}

impl Snap {
    pub const ALL: [Snap; 5] = [Snap::Quarter, Snap::Eighth, Snap::Step, Snap::Half, Snap::Tick];

    pub fn ticks(self) -> u16 {
        match self {
            Snap::Quarter => TICKS_PER_STEP * 4,
            Snap::Eighth => TICKS_PER_STEP * 2,
            Snap::Step => TICKS_PER_STEP,
            Snap::Half => TICKS_PER_STEP / 2,
            Snap::Tick => 1,
        }
    }

    pub fn label(self) -> &'static str {
        match self {
            Snap::Quarter => "1/4",
            Snap::Eighth => "1/8",
            Snap::Step => "1/16",
            Snap::Half => "1/32",
            Snap::Tick => "1/64",
        }
    }
    // floor() unchanged
}

```rust
//! Pure lane geometry for the dock: ticks to x with the dock's shared
//! horizontal scroll, rows to y with the lane's own pitch scroll. Melodic
//! lanes have one row per MIDI pitch (127 on top); drum lanes one row per
//! instrument (the kick at the bottom).

use acid_engine::params::DRUM_INSTRUMENTS;
use acid_engine::project::{Note, TICKS_PER_STEP};
use eframe::egui::{Rect, pos2};

/// Width of one 1/16 step at zoom 1.
pub const STEP_W: f32 = 22.0;
pub const ZOOMS: [f32; 5] = [0.5, 0.75, 1.0, 1.5, 2.0];
const EDGE_PX: f32 = 5.0;

pub fn tick_w(zoom: f32) -> f32 {
    STEP_W * zoom / TICKS_PER_STEP as f32
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Rows {
    Pitches,
    Drums,
}

#[derive(Clone, Copy, Debug)]
pub struct LaneGeom {
    pub left: f32,
    pub top: f32,
    pub tick_w: f32,
    pub row_h: f32,
    pub scroll_x: f32,
    pub scroll_y: f32,
    pub ticks: u16,
    pub rows: Rows,
}

impl LaneGeom {
    pub fn row_count(&self) -> usize {
        match self.rows {
            Rows::Pitches => 128,
            Rows::Drums => DRUM_INSTRUMENTS,
        }
    }

    pub fn row_of(&self, pitch: u8) -> Option<usize> {
        let n = self.row_count();
        ((pitch as usize) < n).then(|| n - 1 - pitch as usize)
    }

    pub fn pitch_of_row(&self, row: usize) -> Option<u8> {
        let n = self.row_count();
        (row < n).then(|| (n - 1 - row) as u8)
    }

    pub fn x_of(&self, tick: u16) -> f32 {
        self.left + tick as f32 * self.tick_w - self.scroll_x
    }

    pub fn tick_at(&self, x: f32) -> Option<u16> {
        if x < self.left {
            return None;
        }
        let t = ((x - self.left + self.scroll_x) / self.tick_w).floor();
        (t >= 0.0 && (t as u32) < self.ticks as u32).then_some(t as u16)
    }

    pub fn tick_at_clamped(&self, x: f32) -> u16 {
        let t = ((x.max(self.left) - self.left + self.scroll_x) / self.tick_w).floor();
        (t.max(0.0) as u32).min(self.ticks.saturating_sub(1) as u32) as u16
    }

    pub fn row_top(&self, row: usize) -> f32 {
        self.top + row as f32 * self.row_h - self.scroll_y
    }

    pub fn pitch_at(&self, y: f32) -> Option<u8> {
        if y < self.top {
            return None;
        }
        let r = ((y - self.top + self.scroll_y) / self.row_h).floor();
        if r < 0.0 {
            return None;
        }
        self.pitch_of_row(r as usize)
    }

    pub fn pitch_at_clamped(&self, y: f32) -> u8 {
        let r = ((y.max(self.top) - self.top + self.scroll_y) / self.row_h).floor();
        let r = (r.max(0.0) as usize).min(self.row_count() - 1);
        self.pitch_of_row(r).unwrap_or(0)
    }

    pub fn note_rect(&self, n: &Note) -> Rect {
        let row = self.row_of(n.pitch).unwrap_or(0);
        let y0 = self.row_top(row);
        let end = n.start.saturating_add(n.len).min(self.ticks);
        Rect::from_min_max(
            pos2(self.x_of(n.start), y0),
            pos2(self.x_of(end), y0 + self.row_h),
        )
    }

    pub fn near_right_edge(&self, n: &Note, x: f32) -> bool {
        (self.note_rect(n).right() - x).abs() <= EDGE_PX
    }
}

/// The horizontal scroll that keeps a playhead at content x `playhead_x`
/// in a view `view_w` wide: unchanged while it sits left of the last
/// quarter of the view, else moved so it sits a quarter in.
pub fn follow_scroll(scroll_x: f32, view_w: f32, playhead_x: f32) -> f32 {
    let margin = view_w / 4.0;
    if playhead_x >= scroll_x && playhead_x <= scroll_x + view_w - margin {
        scroll_x
    } else {
        (playhead_x - margin).max(0.0)
    }
}
```

Check: in `follow_keeps_the_playhead_in_view`, `follow_scroll(0, 400, 350)`: 350 > 300 → `350 − 100 = 250` ✓; `(500, 400, 20)`: 20 < 500 → `max(−80, 0) = 0` ✓. In `pitch_at` with `y = 50 + 9·67.5`: row `67` → pitch `127 − 67 = 60` ✓.

  - `pub struct Cursor { pub tick: u16, pub pitch: u8 }` (`pitch` is an instrument 0..8 on drum lanes).
  - `pub enum LaneKind { Acid, Poly, Drums }`.
  - `pub enum EntryKey { Note(u8), Left, Right, Up, Down, Back }` and `pub fn entry_key(key: egui::Key, mods: egui::Modifiers) -> Option<EntryKey>` — `None` whenever Ctrl/Cmd or Alt is held. The note keys are the tracker layout of the removed step-writer: Z S X D C V G B H N J M = semitones 0..=11; Q 2 W 3 E R 5 T 6 Y 7 U I = 12..=24 (`Comma` is also 12). Arrows map to Left/Right/Up/Down, `Backspace` and `Delete` to Back. No Shift handling.
  - `pub fn apply_entry(roll: &mut NotePattern, cursor: &mut Cursor, key: EntryKey, kind: LaneKind, snap: Snap) -> bool` — true when `roll` changed. Rules:
    - `Left`/`Right`: cursor tick −/+ `snap.ticks()`, wrapping within `roll.ticks()`, snapped to the grid first (`snap.floor`).
    - `Up`/`Down`: pitch ±1 (melodic, clamped 0..=127); drum row ±1 (clamped 0..=7).
    - `Note(semis)`: melodic: the note's pitch is C of the cursor's octave (`cursor.pitch / 12 * 12`) + `semis`, clamped to 127; drums: the cursor's instrument. Adds a note at `snap.floor(cursor.tick)` one snap long (`snap.ticks()`, at least 1) with velocity 100 via `poly_edit::add`; on `Acid` runs `make_mono` on the new index. The cursor's pitch moves to the written pitch (melodic) and its tick advances one snap (wrapping). If `add` refuses (note cap), nothing changes and false is returned.
    - `Back`: deletes the note under the cursor (`note_at(roll, tick, pitch)`), else the note starting nearest before the cursor on the cursor's row within one snap; the cursor stays. False if nothing was deleted.

```rust
//! Keyboard note entry in the dock: the cursor, the tracker key layout and
//! what each key does to the focused lane's pattern. Pure; the dock feeds
//! it key presses while it has keyboard focus.

use super::poly_edit::{Snap, add, make_mono, note_at};
use acid_engine::params::DRUM_INSTRUMENTS;
use acid_engine::project::NotePattern;
use eframe::egui::{Key, Modifiers};

const ENTRY_VEL: u8 = 100;

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct Cursor {
    pub tick: u16,
    /// A MIDI pitch, or an instrument (0..8) on a drum lane.
    pub pitch: u8,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LaneKind {
    Acid,
    Poly,
    Drums,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum EntryKey {
    /// Semitones above C of the cursor's octave (0..=24).
    Note(u8),
    Left,
    Right,
    Up,
    Down,
    Back,
}

pub fn entry_key(key: Key, mods: Modifiers) -> Option<EntryKey> {
    if mods.command || mods.ctrl || mods.alt {
        return None;
    }
    use EntryKey::*;
    Some(match key {
        Key::Z => Note(0),
        Key::S => Note(1),
        Key::X => Note(2),
        Key::D => Note(3),
        Key::C => Note(4),
        Key::V => Note(5),
        Key::G => Note(6),
        Key::B => Note(7),
        Key::H => Note(8),
        Key::N => Note(9),
        Key::J => Note(10),
        Key::M => Note(11),
        Key::Comma | Key::Q => Note(12),
        Key::Num2 => Note(13),
        Key::W => Note(14),
        Key::Num3 => Note(15),
        Key::E => Note(16),
        Key::R => Note(17),
        Key::Num5 => Note(18),
        Key::T => Note(19),
        Key::Num6 => Note(20),
        Key::Y => Note(21),
        Key::Num7 => Note(22),
        Key::U => Note(23),
        Key::I => Note(24),
        Key::ArrowLeft => Left,
        Key::ArrowRight => Right,
        Key::ArrowUp => Up,
        Key::ArrowDown => Down,
        Key::Backspace | Key::Delete => Back,
        _ => return None,
    })
}

fn step(tick: u16, by: i32, ticks: u16) -> u16 {
    (tick as i32 + by).rem_euclid(ticks.max(1) as i32) as u16
}

pub fn apply_entry(
    roll: &mut NotePattern,
    cursor: &mut Cursor,
    key: EntryKey,
    kind: LaneKind,
    snap: Snap,
) -> bool {
    let ticks = roll.ticks();
    let s = snap.ticks().max(1);
    let here = snap.floor(cursor.tick.min(ticks - 1));
    let top = if kind == LaneKind::Drums {
        DRUM_INSTRUMENTS as u8 - 1
    } else {
        127
    };
    match key {
        EntryKey::Left => {
            cursor.tick = step(here, -(s as i32), ticks);
            false
        }
        EntryKey::Right => {
            cursor.tick = step(here, s as i32, ticks);
            false
        }
        EntryKey::Up => {
            cursor.pitch = (cursor.pitch.min(top) + 1).min(top);
            false
        }
        EntryKey::Down => {
            cursor.pitch = cursor.pitch.min(top).saturating_sub(1);
            false
        }
        EntryKey::Note(semis) => {
            let pitch = match kind {
                LaneKind::Drums => cursor.pitch.min(top),
                _ => (cursor.pitch / 12 * 12).saturating_add(semis).min(127),
            };
            let Some(i) = add(roll, here, s, pitch, ENTRY_VEL) else {
                return false;
            };
            if kind == LaneKind::Acid {
                make_mono(roll, i);
            }
            cursor.pitch = pitch;
            cursor.tick = step(here, s as i32, ticks);
            true
        }
        EntryKey::Back => {
            let pitch = cursor.pitch.min(top);
            let tick = cursor.tick.min(ticks - 1);
            let hit = note_at(roll, tick, pitch).or_else(|| {
                roll.notes
                    .iter()
                    .enumerate()
                    .filter(|(_, n)| n.pitch == pitch && n.start <= tick && tick - n.start < s)
                    .max_by_key(|(_, n)| n.start)
                    .map(|(i, _)| i)
            });
            match hit {
                Some(i) => {
                    roll.notes.remove(i);
                    true
                }
                None => false,
            }
        }
    }
}
```
